# BRE@ — Personal Website & Networking Vlog

Personal website and college networking vlog by **Brehanna Sutherland**, built with HTML, CSS, and JavaScript.

**Live Site:** `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`

## Pages
- **Home (`index.html`)**: Interactive digital hardcover book introducing my college journey, key networking themes, collage lightbox, and contact links.
- **About (`about.html`)**: Behind-the-scenes story on creating the networking vlog, design choices, and source citations.
- **Vlog (`vlog.html`)**: Networking video showcase (`Networking.mp4`) with interactive timestamped chapters and project narrative.

## Files Included
- `index.html`, `about.html`, `vlog.html` — Site pages
- `styles.css` — Shared responsive layout and book styling
- `script.js` — Book page-turning, mobile cover open/close, swipe, and lightbox interactions
- `vlog.js` — Timestamped chapter jumping and active chapter tracking
- `image.webp` — College life photo collage
- `Networking.mp4` — Networking vlog video
- `Brehanna_Sutherland_Resume.pdf` — Resume PDF
- `.nojekyll` — Disables Jekyll processing so GitHub Pages serves static files directly
